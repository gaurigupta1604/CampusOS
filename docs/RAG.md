# Document intelligence and RAG

RAG is not yet presented as complete. The planned pipeline is validated upload, PyMuPDF extraction, page-aware cleaning, chunking, sentence-transformer embeddings, pgvector retrieval, reranking, and an optional external LLM response with document/page citations.

Until ingestion is implemented, Campus AI reports its supported live tools and does not claim policy evidence. `GEMINI_API_KEY` remains optional and blank in local development.
